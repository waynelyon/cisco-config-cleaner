# Privacy hardening (proposed)

The AI-safe preset uses labels rather than reversible logical addressing, enables all existing redactions, anonymizes filenames, and enables three independent additional identity options. Explicit username and circuit-ID commands and common MAC spellings are covered. Extra rules apply before preview and export, and do not contribute to the legacy Cisco replacement counters. The complete output still needs review: the preview is bounded. Export checks for suspicious credential-related words and prompts if any match or protections are disabled. This heuristic can produce false positives and miss unsupported secrets; do not treat zero matches as assurance. Logical mode now uses system randomness for each cleaning computation; changing files or options may change mappings. Never consider XOR cryptographic anonymization. The MKA key-chain reference and numeric entry IDs are preserved while actual key-string values are redacted. No new license selected: owner must choose licensing terms. Developer ID signing and notarization require owner credentials. Run native/universal tests before release. Separate RFC1918/public-IP selection remains future work.
