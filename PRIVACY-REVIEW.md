# Privacy hardening — v27.0.2

The AI-safe preset uses labels, enables all privacy controls, and anonymizes filenames. RFC1918, other IPv4 and IPv6 can be retained or replaced independently; mixed selections use labels to avoid collisions. Protocol-special addresses and recognized masks are retained. Known username, SNMPv3, PPP, explicit user diagnostic fields, MAC and circuit identifiers are covered; arbitrary show-tech and unknown fields remain unsupported. Extra substitutions are counted as metadata. Individual credential fields are checked and suspicious cleaned line numbers are shown in preview and the save dialog. These are heuristics, not proof of safe output. Preferences persist; contents and maps do not. Review complete exports beyond preview limits.

Logical mode remains reversible pseudonymization. MACsec references and key IDs are preserved; key material is redacted. Licensing terms have not been selected by the owner; public source access is not an open-source license. Developer ID signing and notarization require owner credentials. No signing or notarization claim is made for ad-hoc builds. See release instructions.
