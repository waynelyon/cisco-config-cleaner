# Security policy

Report suspected credential leaks or sanitizer bypasses privately using GitHub's private vulnerability reporting if enabled, or contact the maintainer privately. Do not post actual customer configuration or secrets in public issues. Use synthetic minimal reproductions. The tool is rules-based and does not guarantee anonymization; inspect all output before sharing. Logical mapping retains topology and is reversible given known pairs. Releases are ad-hoc signed, not notarized. Verify checksums and source.
